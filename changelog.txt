*** CartShift – OpenCart to WooCommerce Migration Changelog ***

2026-05-21 - version 2.5.50
* Added - phpcs.xml configuration to document architectural exceptions (PDO for external DB, table name interpolation, CLI scripts)
* Added - CartShift branding — plugin renamed from OctoWoo to CartShift for WooCommerce Marketplace submission
* Added - changelog.txt in WooCommerce Marketplace required format
* Fixed - Activation warnings on read-only filesystem (QIT sandbox): activator now checks is_writable() before file operations, wp_mkdir_p() return value checked, all file writes are best-effort with silent failure
* Fixed - Logger file writes now use silent @file_put_contents() — DB table is primary log store, file logging is best-effort
* Fixed - Image HTTP fallback URL-encodes path segments so filenames with spaces and parentheses (e.g. "iPhone (8).jpg") download correctly
* Fixed - filter_input() calls replaced FILTER_UNSAFE_RAW with FILTER_VALIDATE_BOOLEAN for boolean flags (dry_run, clear_orders)
* Fixed - filter_input() calls replaced FILTER_SANITIZE_SPECIAL_CHARS with FILTER_SANITIZE_FULL_SPECIAL_CHARS throughout AjaxHandler
* Fixed - $_POST['octowoo'] input sanitized via new deepSanitize() recursive helper (sanitize_textarea_field per value, sanitize_key per key)
* Fixed - $_POST['db_port'] sanitized with absint(), $_POST['db_pass'] with sanitize_text_field + wp_unslash
* Fixed - $_POST['entities'] sanitized with array_map('sanitize_key'), $_POST['config'] with sanitize_textarea_field
* Fixed - $_FILES upload handlers — phpcs:ignore added for PHP-controlled tmp_name paths
* Fixed - Template output escaping: $ow_chk/badge wrapped with esc_attr()/wp_kses_post(), $icon/$status with esc_html(), $bar_w/$pct with (int) cast
* Fixed - LIKE wildcard SQL queries now use $wpdb->esc_like() + %s placeholder in DataPurger, AbstractMigrator, AjaxHandler
* Fixed - error_log() calls annotated with phpcs:ignore QITStandard.PHP.DebugCode — legitimate production server logging
* Fixed - PDO usage in AjaxHandler annotated with phpcs:ignore — required for external OpenCart DB connection ($wpdb is WP-only)
* Fixed - scripts/bump_version.php marked with phpcs:disable — CLI tool, not web-facing
* Fixed - SqlImporter error_log rebranded from OctoWoo to CartShift
* Update - Plugin header: Tested up to WordPress 7.0, WC tested up to 10.7.0, Requires PHP 8.0

2026-05-21 - version 2.5.49
* Fixed - Logs tab now loads most recent run entries automatically after a background migration completes, even when the browser was closed during the run
* Fixed - refreshLogs() resolves to the latest run_id from checkpoints when no currentRunId is present in the browser session
* Fixed - actionGetLogs resolves 'latest' keyword to most recent run_id from wp_octowoo_checkpoints ORDER BY updated_at DESC

2026-05-21 - version 2.5.48
* Fixed - OrderMigrator now warm-loads product, customer and order id_maps in 3 queries instead of 1 DB query per order line item
* Fixed - Orders now have a meta-based duplicate fallback checked in both HPOS and legacy post-table, preventing duplicate orders on re-run after id_map reset
* Fixed - CustomerMigrator warm-loads customer id_map for safe in-memory duplicate detection on re-runs

2026-05-21 - version 2.5.47
* Added - AbstractMigrator::autoFixTempSlugs() scans taxonomies for leftover ow-t-XXXX temp slugs and replaces them with the correct primary-language slug automatically
* Fixed - autoFixTempSlugs() is now called at multilingual pass completion — no manual fix button needed on a fresh migration
* Fixed - autoFixTempSlugs() is called at SeoMigrator first-chunk start — SEO slug-setting always operates on clean slugs even if multilingual was interrupted

2026-05-20 - version 2.5.46
* Fixed - MySQL gone-away detection now checks exception message string before errorInfo[1] code — errorInfo[1] is null when prepare() itself fails, causing the previous retry to silently never fire

2026-05-20 - version 2.5.45
* Fixed - Removed PDO::MYSQL_ATTR_RECONNECT constant which is undefined on some PHP/mysqlnd builds and caused a fatal connection error on activation

2026-05-20 - version 2.5.44
* Fixed - DatabaseConnector::query() now automatically reconnects and retries once on MySQL error 2006 (server has gone away) and 2013 (lost connection). Background migrations no longer crash when the DB connection idles past wait_timeout between batches

2026-05-20 - version 2.5.43
* Added - CheckpointManager::warmIdMapCache(entity) bulk-loads entire id_map for one entity type in 1 SQL query. Re-runs of 6,000+ products now use O(1) in-memory lookups instead of 6,000 DB round-trips
* Added - Multilingual readiness pre-check button scans WooCommerce and reports exact count of missing secondary-language translations per entity type before running the multilingual pass
* Fixed - ManufacturerMigrator now has 3-layer duplicate guard (id_map, term meta with WPML lang filter, name lookup). Brands no longer duplicate on re-runs after id_map reset
* Fixed - CategoryMigrator by_meta SQL now JOINs icl_translations and filters by primary language code. Prevents Arabic WPML stub terms from being returned instead of the English primary category

* Added - Remove Duplicate Brands button merges duplicate brand terms and re-assigns products
